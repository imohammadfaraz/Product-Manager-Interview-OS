# 01. Product Sense & Product Design

**Outcome:** Given an unfamiliar product problem, you can identify a meaningful user need, choose a focused opportunity, propose a testable solution, and explain how you would measure it.

## Use this module when you need to practise

- Designing a product for a new audience.
- Improving an existing product or feature.
- Identifying user segments and unmet needs.
- Moving from a broad problem to a focused opportunity.
- Prioritising solutions without jumping straight to features.

## Your practice sequence

1. Read [Product Sense in Practice](product-sense-playbook.md).
2. Use the [Product Design Answer Canvas](../10-frameworks-templates/product-design-answer-canvas.md).
3. Answer one prompt from the [question bank](question-bank.md) in 20-30 minutes.
4. Review the [worked example](worked-example-improve-a-commute-app.md).
5. Score your answer with the [mock interview scorecard](../09-mock-interviews/scorecard.md).

## A strong answer should show

- A clear user and use context.
- A problem backed by a plausible observation or stated assumption.
- A focused opportunity rather than a feature list.
- Several solution options and a reasoned choice.
- A realistic first release or experiment.
- A primary outcome metric and guardrails.

**Remember:** Product Sense is not a contest to invent the most features. It is a demonstration of judgment about which problem matters and what to do next.
