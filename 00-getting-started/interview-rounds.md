## How to map a job description

1. Highlight repeated verbs: own, define, launch, analyse, influence, scale, discover, monetise, or lead.
2. Highlight the outcomes: adoption, retention, revenue, efficiency, reliability, customer satisfaction, or risk reduction.
3. Highlight the partners: engineering, design, data, operations, sales, legal, security, or leadership.
4. Convert every repeated requirement into a question you may need to answer.
5. Attach one real example or practice exercise to each requirement.

## Example

Job description phrase: "Own activation and onboarding for a B2B product."

Translate it into preparation tasks:

- Explain how you define activation for a multi-user B2B product.
- Build an onboarding funnel and identify drop-off points.
- Discuss user roles such as buyer, administrator, and daily user.
- Describe an experiment that could improve time to first value.
- Prepare a story about aligning design, engineering, and customer-facing teams.

## Final check

Before the interview, you should be able to explain why each planned preparation activity is relevant to the role. If you cannot connect a topic to the job description or likely round, deprioritise it.
