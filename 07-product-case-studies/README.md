# 07. Product Case Study Library

These cases are designed for independent practice. Every company, product, metric, and situation in this section is fictional unless a file explicitly says otherwise. Do not treat the sample numbers as market facts.

## How to use a case

1. Read only the **Candidate brief** first.
2. Set a timer for the suggested duration.
3. Write assumptions before doing calculations.
4. Complete the requested output without reading the guidance.
5. Open the **Facilitator notes** and compare your reasoning.
6. Score yourself using the rubric and record one improvement.

## Facilitation guidance

If practising with a partner, give the candidate only the brief. Reveal additional information only when they ask a relevant question. Do not reward guessing hidden facts. Reward candidates who identify what they would need to know and how they would obtain it.

## Generic evaluation rubric

Score each dimension from 1 to 5:

- Problem framing and assumptions.
- User and business understanding.
- Use of evidence and data.
- Options and prioritisation.
- Feasibility and execution.
- Metrics, risks, and communication.

A strong candidate does not need to choose the same solution as the facilitator notes. They need a coherent, evidence-aware recommendation.
