# Job Description to Interview Map

Use this worksheet to turn vague job requirements into preparation priorities.

## Step 1: Extract the verbs

Highlight verbs such as define, lead, launch, analyse, grow, prioritise, influence, discover, scale, monetise, govern, and communicate. Each verb implies a capability or decision.

## Step 2: Map each requirement

| Job description phrase | Likely competency | Evidence I can demonstrate | Question to practise | Gap to close |
|---|---|---|---|---|
| Own product strategy | Vision, market, trade-offs | | | |
| Improve activation | Funnel analysis, discovery, experimentation | | | |
| Work with Engineering | Technical fluency, execution | | | |
| Influence stakeholders | Communication, conflict resolution | | | |
| Define success metrics | Analytics, outcome orientation | | | |
| Lead cross-functional teams | Leadership, alignment | | | |

Replace these sample phrases with the exact language from your target role.

## Step 3: Prioritise preparation

Score each competency:

- **Role importance:** 1-3.
- **Your current confidence:** 1-5.
- **Evidence strength:** 1-5.

Prioritise high-importance areas where confidence or evidence is weak. Do not spend equal time on every topic.

## Step 4: Prepare evidence, not claims

For every important competency, identify one story, artefact, or exercise that demonstrates it. Be ready to explain your role, decision, trade-off, result, and learning.

## Step 5: Validate your interpretation

Ask the recruiter or hiring manager which competencies are most important in the role and what the interview loop will cover. Your map is a hypothesis until validated.
