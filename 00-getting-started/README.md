# 00. Getting Started

Use this module to understand the interview process, choose the skills to practise, and set up a repeatable preparation routine.

## Complete these steps

1. Read the [PM Interview Handbook](pm-interview-handbook.md).
2. Review the [PM Competency Matrix](competency-matrix.md) and mark your current evidence.
3. Use the [Interview Round Map](interview-rounds.md) to map the process you have been told to expect.
4. Run the baseline questions in [Start Here](../START-HERE.md).
5. Choose a preparation plan from [Module 11](../11-preparation-plans/README.md).

**Your output:** A target-role brief, a list of priority competencies, and a weekly practice schedule.
