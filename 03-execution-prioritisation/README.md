# 03. Execution & Prioritisation

**Outcome:** You can turn goals into a practical sequence of work, make capacity decisions, manage dependencies, and communicate delivery trade-offs.

## Work through the module

1. Read the [Execution Interview Playbook](execution-interview-playbook.md).
2. Practise with [Prioritisation Frameworks](prioritisation-frameworks.md).
3. Use the [Delivery and Stakeholder Guide](delivery-and-stakeholder-guide.md).
4. Answer the [Execution Question Bank](question-bank.md).
5. Use the [Prioritisation Decision Canvas](../10-frameworks-templates/prioritisation-decision-canvas.md).

**Your output:** A prioritised decision with criteria, capacity assumptions, owners, dependencies, risks, and a communication plan.
