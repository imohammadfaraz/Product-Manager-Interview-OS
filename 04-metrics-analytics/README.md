# 04. Metrics & Analytics

**Outcome:** You can define meaningful product measures, build a metric tree, diagnose a change, design an experiment, and explain what the data does and does not prove.

## Complete this module

1. Read [Metrics for PM Interviews](metrics-for-pm-interviews.md).
2. Practise [Metric Diagnosis](metric-diagnosis-playbook.md).
3. Review [Experiment Design](experiment-design.md).
4. Complete the [SQL for PMs Lab](sql-for-pms/README.md).
5. Answer the [Metrics Question Bank](question-bank.md).

## Your deliverable

For one product problem, create a metric tree, define a primary outcome and guardrails, outline an investigation or experiment, and state the decision rule.
