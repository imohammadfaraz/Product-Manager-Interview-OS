# 09. Mock Interviews

**Outcome:** You can practise under realistic conditions, respond to follow-up questions, and identify specific improvements.

## How to run a mock interview

### Candidate

1. Read only the opening prompt.
2. Ask clarifying questions and state assumptions.
3. Think aloud. Make your reasoning visible.
4. Answer the interviewer's follow-ups without becoming defensive.
5. End with a recommendation, trade-offs, and measures.
6. Ask for feedback before seeing the rubric.

### Interviewer / practice partner

1. Read the interviewer instructions in the selected script.
2. Do not reveal facilitator notes or ideal-answer guidance.
3. Ask one question at a time.
4. Probe assumptions, evidence, prioritisation, and consequences.
5. Give feedback using observable evidence, not personality labels.
6. Ask the candidate to repeat the weakest section.

## Score and review

Use the [Mock Interview Scorecard](scorecard.md). Record the question, score, evidence, and one action to improve. Re-run a similar question after 48-72 hours to check whether the improvement transfers.

## Feedback rule

Give feedback in this format: "When you did X, the answer became clearer / less clear because Y. Next time, try Z." Avoid vague feedback such as "be more strategic" or "show more confidence" without explaining the behaviour that would demonstrate it.
