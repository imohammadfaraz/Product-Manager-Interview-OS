# 10. Frameworks & Templates

Use these worksheets to make your reasoning visible. Copy a template into your notes before a practice session. Frameworks are tools, not scripts. Skip sections that do not help answer the actual question.

| Template | Use it for |
|---|---|
| [Product Design Answer Canvas](product-design-answer-canvas.md) | Design or improve a product. |
| [Strategy Decision Memo](strategy-decision-memo.md) | Choose a market, segment, or strategic bet. |
| [Prioritisation Decision Canvas](prioritisation-decision-canvas.md) | Compare initiatives and explain trade-offs. |
| [Metric Diagnosis Worksheet](metric-diagnosis-worksheet.md) | Investigate a change in a product metric. |
| [Experiment Brief](experiment-brief.md) | Test a product hypothesis. |
| [Market Sizing Worksheet](market-sizing-worksheet.md) | Build a transparent opportunity estimate. |
| [Behavioural Story Worksheet](behavioural-story-worksheet.md) | Prepare a truthful STAR-L example. |
| [Product Teardown Worksheet](product-teardown-worksheet.md) | Analyse a product journey. |
| [Launch Readiness Checklist](launch-readiness-checklist.md) | Check customer and operational readiness. |
| [Decision Log](decision-log.md) | Record a decision and revisit trigger. |

## How to avoid framework misuse

- Start with the question, not the framework name.
- Use only the steps that help with the decision.
- Explain assumptions and uncertainty.
- Show the trade-off and recommendation.
- Connect the output to a practical next step.
